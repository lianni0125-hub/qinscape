# Third-party preset voice provenance

The bundled Qinscape preset reference voices are synthetic audio generated from
the Mandarin voice packs of `hexgrad/Kokoro-82M-v1.1-zh`.

- Upstream: https://huggingface.co/hexgrad/Kokoro-82M-v1.1-zh
- Inference library: https://github.com/hexgrad/kokoro
- License: Apache License 2.0
- Local preset names are product labels and do not represent real people.

The generated reference audio is used only as timbre conditioning input for the
configured singing synthesis pipeline. Preserve this notice when redistributing
the preset reference voices.
